# Tech Stack

## Frontend
- **Framework**: React (Vite)
- **Language**: TypeScript
- **Styling**: TailwindCSS (inferred from usage patterns, verify if uncertain)
- **Editor**: Monaco Editor (`@monaco-editor/react`)

## Backend
- **Runtime**: Node.js
- **Server**: Express
- **Build Tool**: `ucc-gen` (Python CLI) for Splunk app compilation
- **Language**: TypeScript (transpiled)

## Key Libraries
- **VFS**: Custom recursive Map-based file system (`src/lib/vfs.ts`)
- **Spec Parser**: Custom Splunk `.spec` file parser (`src/lib/specParser.ts`)
- **OpenRouter**: AI integration provider (planned)

## Environment
- **OS**: Mac (User's OS)
- **Splunk Base**: Standard UCC framework compliance
